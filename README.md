# AIquainted local storefront

Unpublished static preview for solo service-business owners. It presents the exact v1.0.0 deliverables: The 15-Minute AI Workflow Finder (free, 4-page PDF) and Weekly Customer Communication Sprint (planned one-time price $29; 7 workflow cards, 2 synthetic examples).

Lead capture, delivery, checkout, support, and analytics are disabled in assets/config.js. Do not enable them until the corresponding legal, privacy, support, delivery, payment, webhook, and end-to-end test gates pass.

Run locally with a static HTTP server on this directory.
